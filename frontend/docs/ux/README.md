## Peça visual

As versões visuais (pranchas P1–P3 de personas e J-A / J-B de jornada) estão na página **"jornada do usuário"** do arquivo Figma `Frontend-Projeto-Inter`. Estes Markdown são a **fonte textual completa**; as pranchas condensam o mesmo conteúdo para apresentação.

## Fontes

- TAP do projeto (`docs/TAP-Banco-Inter.pdf` no repositório vitrine `InteliBlockchain-IBC/projeto-banco-inter`)
- Entregáveis do ciclo (`docs/Entregaveis-Banco-Inter.pdf`, mesmo repositório)
- Wireframes WEB 01–10 do Figma

## Status e como atualizar

- Versão 0.1 (20/09/2026), **proposta**. Nomes, bancos e valores são fictícios; não há dados reais do Banco Inter.
- Ao validar com o time ou com o parceiro, atualize primeiro o Markdown, depois a prancha correspondente no Figma, e registre a versão e a data na tabela de cabeçalho de cada documento.
- Itens marcados `[DEFINIR com Web3]` dependem da máquina de estados do contrato.
